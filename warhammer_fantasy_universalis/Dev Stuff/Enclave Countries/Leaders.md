# Enclave rebel leaders

Each Root Out decision uses `size = 3`, the enclave's primary culture and religion, `nationalist_rebels`, `win = yes`, and its own E## tag for both `friend` and `separatists_target`.

Names are split between the engine's `leader` and `leader_dynasty` fields following the installed EU4 script examples. For characters known by an epithet, that byname occupies the second field; it is not a claim that the epithet is a hereditary dynasty. Characters with a single recorded name have an explicit empty dynasty. Female leaders also receive `female = yes`.

38 choices use documented characters or a documented office; 62 are original leaders for invented factions or factions without a verified suitable leader. The faction's location, culture, or chronology can still be the approved mod adaptation.

## Mechanics references

- The mod's `common/rebel_types/nationalist.txt` defines `nationalist_rebels` as separatists.
- Installed EU4 `events/flavorVIJ.txt` uses both `leader` and `leader_dynasty` for separatists; `events/flavorSON.txt` also demonstrates culture/religion overrides. Installed `common/on_actions/00_on_actions.txt` identifies release scope as the released country and ownership-change scope as the province.
- [CWTools EU4 effect schema](https://github.com/cwtools/cwtools-eu4-config/blob/master/effects.cwt) documents `spawn_rebels`, including `size`, `culture`, `religion`, `win`, `friend`, `separatists_target`, `leader`, and `leader_dynasty`.
- `Dev Stuff/Examples/Balance Guide.txt` and `Lore Reference.txt` were consulted. Rebellion size and province penalties use the user's exact requirements, outside the random-event option budgeting rules.
