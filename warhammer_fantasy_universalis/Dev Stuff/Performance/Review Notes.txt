PERFORMANCE CHANGES AND VANILLA REFERENCE REVIEW — 23 OCTOBER 2026

Implemented

- End Times completion: is_great_power plus NOT great_power_rank = 2 selects only
  the leading great power. The existing completion condition and MTTH are unchanged.
- Artifacts: 24 saved global province locations replace world/ownership searches
  in capture decisions, diplomatic gifts/requests, relocation and collection missions.
  All scripted additions/transfers update the location; consumption clears it.
  A one-time startup scan discovers actual locations in both new and existing saves.
  Missing artifacts return false without accessing unset targets. Nagash has a saved
  country target, and the defeat decision reads that country's current capital.
  The system assumes one copy of each artifact; province history satisfies this.
  An externally edited save with duplicate artifact modifiers needs separate cleanup.
- Tomb Kings: ten monument quota branches now check only the five relevant fixed
  monument sites each, preserving exact tiers, quotas and subject ownership rules.
- Pigbarter: regional settlement quotas search only their named area/region; Vorag
  checks its eight named provinces. Commercial partners use the ally list.
  The three trust objectives now require distinct allies or subjects: 2 at 60 trust,
  3 at 90 trust, and 4 at 75 trust. Allies that are also subjects count once.
- Nippon: homeland, Khuresh, underground and New World searches use direct geographic
  scopes. Related mission highlights and both mission design sources are synchronized.
- Relationship objectives: 18 objectives and three related highlight conditions use
  allies, subjects or war enemies instead of all countries; other conditions remain.
  Redundant alliance, war and subject checks are omitted within their respective
  relationship scopes. Westerland uses the
  native num_of_allies counter for its unfiltered three-ally requirement.
- Warpmoon: immovable in province 4600, with direct potential/allow/effect checks.
- Ogre Great Feast: checks province 1215's owner directly for military access.

Vanilla-reference list

Start with Vanilla Reference Audit.txt for counts and the polled-event/decision index.
vanilla_condition_candidates.csv groups 468 definitions for review.
vanilla_reference_inventory.csv gives all 2,725 matches, including effect/setup uses,
exact lines, nesting, evaluation sites and identifier catalog status.
The audit covers active mod .txt scripts, not unoverridden files inherited from EU4.
All matching comments and backup files are excluded. Three pre-existing brace errors
were recovered for inventory and are listed in the audit; their files were not edited.
Run audit_vanilla_references.py to regenerate these lists after other script changes.

Recommended review order (no candidates have been disabled)

1. PropagateReligionEvents.txt, propagate_religion_events.11 (Muslim Refugees).
   A polled province event searches all countries for Muslim propagation activity.
   This is the strongest candidate from the original performance finding, assuming
   no intended Warhammer mechanic creates Muslim countries or that propagation policy.
   The same file has nine triggered vanilla-religion event definitions to review with
   their on_action/event callers before disabling the whole chain.

2. Positive vanilla-faith requirements in polled events.
   Dynastic.txt: 9450 (Catholic), 9457, 9460, 9470, 9481 and dynastic_events.1 (Christian).
   Devotion.txt: devotion_events.105 (Christian) and devotion_events.206 (Muslim).
   ColonialNation.txt: colonial_nation.191 (Catholic).
   institutions.txt: institution_events.73 (Christian or Muslim).
   NewCourtFlavorEvents.txt: new_court_flavour_events.39 (PAP/Catholic targets).
   These have faith-dependent firing conditions; review whether each is intended to
   be adapted to the mod, or can have its entire event block commented out.

3. Vanilla geography in mod-specific content.
   war_PriceChanges.txt: war_prices.27 requires indo_china_region; war_prices.31 excludes
   arabia_region. The former looks like a stale location to retarget or disable; the
   latter is a negative filter and may still be intended to fire for WFU provinces.
   MercenaryEvents.txt: mercs.5 references india_superregion; check both OR branches.
   PirateGovernment.txt: become_pirates_decision includes maghreb_region in a branch.
   Use the CSV to review other area/region/trade-node/culture references individually.

4. Shared triggers and triggered event chains.
   Forty scripted-trigger definitions contain vanilla checks, especially in
   common/scripted_triggers/00_scripted_triggers.txt and the Muslim-school helpers.
   Follow their callers before commenting out definitions; otherwise callers become
   undefined triggers. The inventory includes government, estate, diplomatic and
   scripted-effect condition blocks too, since these can be evaluated repeatedly.

Do not blanket-disable every listed definition

- consort_events.52 excludes Tengri/Confucian faiths; that does not make it irrelevant
  to Warhammer. dynastic_events.2 and .3 similarly exclude Muslim faiths.
- consort_events.1/.102/.103/.314, colonial_nation.189, personality_events.2,
  random_event.22 and new_court_flavour_events.20 have listed references in optional
  outcomes, weights or effect conditions; their main triggers are broader.
- estate_privileges_and_agendas_events.2 contains a Hindu branch alongside generic
  noble, burgher and church branches. Remove/adapt only the obsolete branch if needed.
- cossack_estate_events.2 uses negative geography filters and otherwise generic
  province/estate logic. Assess the remaining event, not just the old region names.
- Europe, Asia, Africa, North/South America and other continent identifiers are
  intentionally repurposed for the Warhammer map. The audit marks these for retention.
- The mod still defines 27 of the base game's 28 religion IDs. Catalog presence alone
  does not establish intended playability; absent starting populations do not prove
  that event, rebel or country-creation paths cannot introduce them later.
- References marked unclassified exact identifier need the key inspected: for example
  technology_group = muslim is not itself a religion-group test.
